# Automatic Yupoo Photo Downloader

Basically, you add the URL of the Yupoo page or category you want to download, and the script will automatically enter each album folder to download all photos.

- **rename.py**: Renames any downloaded files that contain invalid characters.  
- **cookies.py**: Lets you supply a password if your supplier’s Yupoo album is protected.

It’s super simple and easy to use—I couldn’t find anything on GitHub that does this as cleanly.

Cheers.

# Script desenvolvido para realizar o download automático de fotos do site Yupoo. 
### Basicamente, você adiciona a URL da página/categoria que deseja baixar e ele entra sozinho em cada pasta para realizar o download de todas as fotos.

O rename.py serve para renomear arquivos que vem com algum caracter inválido. 
O cookies.py serve para adicionar a senha, caso tiver no drive yupoo de seu fornecedor.
